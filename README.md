## Architecture
### Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
For this project, I utilzied 2 different front end interfaces, one, a static site with multiple pages for the customer userbase, powered by node.js and handlebars, utilizing , as well as a page for purchasing travel packages powered by a mongoDB database. The other front end interface was a single-page application, powered through angular.js for use by the admins to modify, and adding to the database powering the travel packages database.
### Why did the backend use a NoSQL MongoDB database?
The backend utilized a NoSQL MongoDB database for both the Administator login and the travel packages, for the purpose of scalability, so that as many users and trips could be added as necessary, and the ability for the data to be updated in real time with no restarts or refreshes required.
## Functionality
### How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?
Json (JavaScript Object Notation) is a file format for structuring data. Javascript, meanwhile, is a scripting language, used to create functions and logic, primarily for the purose of webpages. Json will interact with the javascript code as data for the code to parse in order to display the web page contents to the front end user.
